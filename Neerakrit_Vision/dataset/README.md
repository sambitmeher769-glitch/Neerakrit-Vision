# Dataset

The images themselves are not in this zip (about 2 GB). Every image used is listed in
`manifest.csv` with its path inside the public source repository, so the set can be rebuilt.

| file | contents |
|---|---|
| manifest.csv | 24,676 rows: image_path, source, split (train/test), is_leaf, label |
| classes.csv | the 38 classes the model predicts, with crop, condition and healthy flag |
| summary.csv | image counts per source and split |
| test_results.json | accuracy on the held-out test images |

## Sources
| source | what | train | test |
|---|---|---|---|
| PlantVillage | lab photos of single leaves, 38 classes | 18,201 | 1,520 |
| PlantDoc | field photos collected from web image search | 2,342 | 236 |
| ImageNet sample | everyday objects, people, animals (non-leaf) | 1,577 | 300 |
| Synthetic | soil, skin, walls, plain backgrounds (non-leaf) | 450 | 50 |

- PlantVillage: https://github.com/spMohanty/PlantVillage-Dataset
- PlantDoc: https://github.com/pratikkayal/PlantDoc-Dataset
- ImageNet samples: https://github.com/EliSchwartz/imagenet-sample-images and https://github.com/ajschumacher/imagen
- Synthetic images are generated by `training/cache.py`.

ImageNet classes with plant-related names (corn, cabbage, flowerpot, daisy and similar)
were removed from the non-leaf set so real plants are never labelled "not a leaf".

## Test results (images never used in training)
- PlantVillage lab photos: 99.5% correct (1,520 images), correct class in top 3: 99.9%
- PlantDoc field photos: 64.8% correct (236 images), correct class in top 3: 86.4%
- Healthy vs diseased mix-ups on lab photos: 0
- Non-leaf images wrongly passed as leaf: 6 of 350
- Leaf images wrongly locked as not-leaf: 1 of 1,756
